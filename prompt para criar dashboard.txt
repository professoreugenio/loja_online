Atue como um desenvolvedor web pleno especializado em HTML5, CSS3, Bootstrap 5, Bootstrap Icons, acessibilidade, responsividade e interfaces administrativas.

Crie uma página completa chamada `dashboard.html` para o painel administrativo de uma loja online.

A página pertence a um projeto PHP que utiliza um controlador de rotas. Portanto, todos os links devem apontar para rotas do sistema, e nunca diretamente para arquivos `.html` ou `.php`.

O projeto está sendo executado inicialmente em:

http://localhost/loja_online/public/

Adicione dentro da tag `<head>`:

<base href="/loja_online/public/">

Dessa forma, utilize links relativos como:

- `href="admin"` para o dashboard;
- `href="admin/produtos"` para produtos;
- `href="admin/clientes"` para clientes;
- `href="admin/pedidos"` para pedidos;
- `href="admin/estoque"` para estoque;
- `href="admin/configuracoes"` para configurações.

Não utilize links como:

- `dashboard.html`;
- `produtos.html`;
- `dashboard.php`;
- `views/admin/dashboard.php`;
- `../produtos.php`.

## Contexto da estrutura do projeto

Considere a seguinte organização:

loja_online/
├── public/
│   ├── assets/
│   ├── .htaccess
│   └── index.php
├── routes/
│   ├── admin.php
│   ├── logadm.php
│   └── site.php
├── src/
├── storage/
├── vendor/
└── views/
    └── admin/
        └── dashboard.html

As rotas administrativas serão controladas principalmente pelo arquivo:

routes/admin.php

A autenticação e a saída administrativa serão controladas pelo arquivo:

routes/logadm.php

O acesso público à loja será controlado pelo arquivo:

routes/site.php

## Tecnologias obrigatórias

Utilize:

- HTML5 semântico;
- Bootstrap 5.3.8;
- Bootstrap Icons;
- CSS personalizado dentro da tag `<style>`;
- Bootstrap Bundle antes do fechamento da tag `</body>`;
- JavaScript puro apenas quando necessário.

Não utilize:

- jQuery;
- React;
- Vue;
- Angular;
- Tailwind;
- bibliotecas de gráficos;
- frameworks adicionais;
- código PHP nesta primeira versão.

O arquivo deve funcionar inicialmente como uma demonstração visual em HTML.

## Estrutura visual geral

Crie um dashboard administrativo moderno contendo:

1. menu lateral;
2. barra superior;
3. área principal;
4. cards de indicadores;
5. acessos rápidos;
6. tabela de pedidos recentes;
7. tabela de estoque baixo;
8. painel de notificações;
9. resumo operacional;
10. rodapé administrativo.

O layout deve funcionar em:

- celulares;
- tablets;
- notebooks;
- monitores grandes.

## 1. Menu lateral

Crie um menu lateral fixo para computadores e um menu Offcanvas do Bootstrap para celulares e tablets.

No topo do menu, exiba:

- ícone de loja;
- nome “Loja Online”;
- texto “Painel administrativo”.

O menu deve possuir as seguintes divisões.

### Visão geral

Adicionar:

- Dashboard: `admin`;
- Relatórios: `admin/relatorios`.

### Cadastros

Adicionar:

- Produtos: `admin/produtos`;
- Categorias: `admin/categorias`;
- Clientes: `admin/clientes`.

### Vendas

Adicionar:

- Pedidos: `admin/pedidos`;
- Pagamentos: `admin/pagamentos`;
- Carrinhos ativos: `admin/carrinhos`.

### Controle

Adicionar:

- Estoque: `admin/estoque`;
- Notificações: `admin/notificacoes`;
- Contatos: `admin/contatos`;
- Configurações: `admin/configuracoes`.

Na parte inferior do menu, adicionar:

- Visualizar loja: `href=""`;
- Sair do sistema por formulário POST para `admin/sair`.

O acesso “Visualizar loja” deve abrir em uma nova aba.

Exemplo:

<a href="" target="_blank">
    Visualizar loja
</a>

O botão “Sair” não deve utilizar um link GET.

Utilize:

<form action="admin/sair" method="post">
    <button type="submit">
        Sair do sistema
    </button>
</form>

Como o arquivo ainda será HTML, não adicione token CSRF nesta primeira versão. Porém, inclua um comentário informando que o token deverá ser acrescentado quando a página for convertida para PHP.

## 2. Barra superior

Crie uma barra superior fixa ou aderente no topo.

A barra deve possuir:

- botão para abrir o menu em celulares;
- campo de pesquisa;
- ícone de notificações;
- número de notificações não lidas;
- avatar do administrador;
- nome “Administrador”;
- menu suspenso da conta.

O formulário de pesquisa deve:

- utilizar `method="get"`;
- utilizar `action="admin/buscar"`;
- possuir campo com `name="q"`;
- ter label acessível;
- possuir ícone de pesquisa.

O menu da conta deve conter:

- Meu perfil: `admin/perfil`;
- Configurações: `admin/configuracoes`;
- Sair por formulário POST: `admin/sair`.

- Pago;

- Enviado;
- Entregue;
- Cancelado.

Exemplo de rota:

admin/pedidos/1058

admin/pedidos

A tabela deve estar dentro de um elemento com a classe:

table-responsive

## Responsividade

No computador:

- menu lateral fixo;
- conteúdo principal ao lado do menu;
- barra superior visível;
- cards distribuídos em várias colunas.

No celular e tablet:

- ocultar o menu lateral fixo;
- utilizar Offcanvas do Bootstrap;
- apresentar botão para abrir o menu;
- permitir rolagem horizontal nas tabelas;
- empilhar cards e painéis;
- adaptar o campo de busca;
- evitar conteúdo cortado.

## JavaScript

Utilize JavaScript puro somente para:

- atualizar o ano do rodapé;
- identificar a rota atual;
- destacar o link ativo do menu;
- complementar o funcionamento do layout.

Não implemente:

- autenticação real;
- comunicação com banco de dados;
- requisições AJAX;
- gráficos;
- exclusão de registros;
- atualização de dados;
- valores dinâmicos reais.

Os dados devem ser apenas demonstrativos.

## Segurança

Inclua comentários explicando que:

- a página deverá ser convertida para `dashboard.php`;
- o administrador deverá estar autenticado antes de acessar;
- os números do dashboard deverão vir do banco de dados;
- o formulário de saída deverá receber um token CSRF;
- o acesso deve ocorrer pela rota, e não diretamente pelo arquivo dentro de `views`.

Não coloque senha, token, chave de API ou dado sensível no HTML.
